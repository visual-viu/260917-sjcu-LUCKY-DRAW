# AI창작학과 Lucky Draw

2026 세종사이버대학교 한마음축제 AI창작학과 럭키드로우입니다.

## 페이지
- `/` 메인
- `/draw` 럭키드로우
- `/hall-of-fame` 명예의 전당
- `/admin` 운영자 페이지

## 데이터
Supabase를 사용해 상품 재고, 당첨자, 추첨 로그를 여러 기기에서 공유합니다.

## 운영자
관리자 PIN은 Vercel Environment Variable의 `ADMIN_PIN` 값을 사용합니다.

운영자 페이지에서 상품 추가/이름 수정/삭제, 상품 재고 조정, 당첨자 확인, 당첨자 개별 삭제, 삭제 시 재고 복구, 전체 초기화가 가능합니다.
당첨자 일시는 날짜와 시:분:초까지 표시됩니다.

## 꽝(비당첨) 수량
꽝은 더 이상 매 추첨 50% 확률로 나오지 않고, 상품처럼 총/남은 수량을 가진 별도 항목으로 관리됩니다.
- 추첨은 "남은 상품 수량 + 남은 꽝 수량"에 비례한 가중치로 뽑히며, 꽝이 뽑히면 그 즉시 남은 꽝 수량이 1 줄어듭니다.
- 꽝 수량이 0이 되면 이후 추첨은 모두 당첨 처리됩니다. 즉, 전체 추첨 가능 횟수(상품 총합 + 꽝 총합)를 행사 참가 인원수에 맞춰 고정할 수 있습니다.
- 운영자 페이지의 "꽝(비당첨) 수량 관리" 섹션에서 −/＋ 버튼으로 미세 조정하거나 "수량설정"으로 총 수량을 한 번에 바꿀 수 있어, 행사 중 인원이 늘거나 줄어도 대응할 수 있습니다.
- 최초 배포 시 `supabase/Lucky_draw_blank_quota.sql`을 Supabase SQL Editor에서 1회 실행해야 합니다 (prizes 테이블에 `is_blank` 컬럼과 꽝 전용 행을 추가하고 `draw_lucky_prize()` 함수를 교체합니다). 실행 전까지 꽝 남은 수량은 0이라 모든 추첨이 당첨으로 처리됩니다.

## 현재 상품
- CGV 영화 예매권 10명
- 향기 캡슐세제 5명
- 캐릭터 굿즈 맥세이프 10명

> Environment Variable을 새로 추가하거나 변경한 경우 새 배포가 필요합니다.
